# Privacy Policy

`signal-desktop-forensic` is an offline, open-source Rust library. It performs
no network communication, collects no telemetry, and transmits no data. All
parsing runs locally against artifacts the operator supplies.

The library processes decrypted Signal Desktop content in memory only for the
duration of a call and writes nothing except what the calling program chooses to
persist. Handling of the recovered content is the operator's responsibility and
subject to their own legal authority and data-protection obligations.
